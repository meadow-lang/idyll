# Idyll

The official implementation of the Idyll programming language

New to the language? Start with the [tutorial](TUTORIAL.md).

## AI disclosure

Idyll is written with AI coding agents: Anthropic's Claude, through Claude Code.
Most of the code, the tests, the documentation and the commit messages in this
repository were written by an agent, under the direction of the project's
author, who decides the design and what goes in. Read it, and rely on it, with
that in mind.

## Goals

- Pure functional programming
- Static types
- Row polymorphism
- Higher kinded types (HKTs)
- Monadic effect handling
- Linear types
- Lisp-like hygienic macros on token trees
- Optional indentation sensitivity
- Lazy evaluation by default
- VM runtime
- Fast compile times
- JIT compilation
- Tunable compiler and runtime
- Interactive programming
- Omniscient debugging
- IDE with multiple views of the code
- Platform-independent distributable low-level IR
- Visual programming
- Runtime monitoring and reflection
